# DevSphere — EM.Subhan ali Portfolio

A state-of-the-art, high-performance personal portfolio, creative technologist showcase, and robotics engineering architecture platform built with modern HTML5, Vanilla CSS3, JavaScript (ES6+), and an embedded SQLite database backend.

## 🌟 Key Features
- **Cyber-Luxury Glassmorphic UI:** Modern aesthetic with fluid canvas animations and dynamic 3D card tilt effects.
- **Embedded SQLite 3 Database:** Native ACID-compliant storage for client leads, inquiries, and reviews.
- **Secret Admin Control Panel:** 5 rapid sequential taps on the brand icon (`</>`) unlocks full real-time customization without code changes.
- **Interactive Terminal CLI:** Built-in command-line interface for exploring skills, projects, and executing simulated developer tasks.
- **Visitor Access & Lead Gate:** Seamless lead capture modal for potential clients and recruiters.

## 🚀 Quick Start Locally
To run the server and database locally:
```bash
node server.js
```
Or simply double-click `start-live.bat`.

- **Website:** `http://localhost:3000`
- **Database Manager:** `http://localhost:3000/database`
